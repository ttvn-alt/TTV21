# TikTok Coins Exchange — Mobile Web App

A pixel-perfect, high-fidelity TikTok Coins Exchange mobile application built with React, Vite, and Lucide Icons.

## 🚀 Features

- **Screen 1: Search & Select**:
  - Exchange Header & TikTok Coins Balance (`$856,647,390.22`).
  - Equivalent coin conversion display `~ $856,647,390.22 (🪙 70,587,586,600)`.
  - Search input with `@username` placeholder and mock auto-complete card for `@happy_momonga`.
  - Animated loading spinner transition.

- **Screen 2: Exchange Completed!**:
  - Green checkmark header icon.
  - Receipt details (Recipient `@happy_momonga`, Coins Exchanged `5,000,000 Coins`, Deducted Amount `$60500.00`).
  - **Dubai Timezone Timestamp**: Formatted dynamically in GST (`Asia/Dubai`) as `9/6/2026, 1:02:11 AM`.
  - Gifter level promo banner.
  - Action pill button returning state back to search.

## 🛠️ Tech Stack

- **Framework**: React + Vite
- **Styling**: Vanilla CSS (Mobile App Design System)
- **Icons**: Lucide React

## 📦 GitHub Deployment

Target Repository: `https://github.com/ttvn-alt/TTV21`

To push this codebase to your GitHub repository, open your terminal in this directory and run:

```bash
git remote add origin https://github.com/ttvn-alt/TTV21.git
git branch -M main
git push -u origin main
```

To deploy the live app to GitHub Pages:

```bash
npm run deploy
```
